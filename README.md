# Tents

A tiny always-on-top Tents puzzle window for macOS. Grid sizes 5×5 to 8×8, levels Easy / Medium / Hard / Kushal.

**[Download Tents.dmg](https://github.com/hansanaab/tents/releases/latest/download/Tents.dmg)**: open it and drag Tents into Applications.

The app isn't notarized, so the first launch shows "can't be verified". Click **Done**, then go to
**System Settings → Privacy & Security → Open Anyway**.

## Controls
- Left click: empty → tent → grass
- Right click / drag: mark grass
- ✕ (bottom-right corner) or Esc: end game and return to the menu
- N new game · R reset · 1–4 level · T always-on-top

Or run from source: `python3 tents.py`
